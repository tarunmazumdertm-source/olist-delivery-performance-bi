# Project Management — GR05 Olist BI & Big Data Project

This folder contains the project-management baseline for the GR05 project **From Order to Review: How delivery performance affects customer satisfaction and sales**.

**Planning boundary:** This version covers preparation and deliverables up to the Milestone Presentation on **13 November 2026** (calendar Week 46). Work after that milestone is intentionally not planned in this version. The team can update this folder after reviewing the presentation feedback.

## Documents

1. `01_Project_Charter.md` — project background, business problem and intended value.
2. `02_Scope_Objectives_and_Constraints.md` — project scope, objectives, outcomes and constraints.
3. `03_Team_Roles_and_Responsibilities.md` — current task owners and the functional roles described in the proposal.
4. `04_Milestone_Plan_to_13_Nov_2026.md` — deliverables up to the current milestone.
5. `05_Risk_Register_and_Mitigations.md` — proposal risks and planned responses.
6. `06_Decision_Log.md` — decisions and baseline assumptions recorded so far.
7. `07_Meeting_Minutes_Template.md` — template for recording team meetings.
8. `08_Milestone_Readiness_Checklist.md` — checklist for the 13 November presentation.
9. `PROJECT_MANAGEMENT_BASELINE_TO_13_NOV_2026.md` — consolidated project-management document.

## How the team should use this folder

- Keep agreed project scope and responsibilities here.
- Record changes as dated entries in the decision log.
- Record meeting outcomes and action owners in `05_Meeting_Minutes/`.
- Use GitHub Issues or GitHub Projects for live task status; do not maintain duplicate status updates in several files.
- Make updates through a branch and Pull Request so the `main` branch remains the approved project record.
- Do not store the raw Olist CSV files in this folder or commit them to GitHub.

## Status convention

The documents describe the agreed baseline and planned deliverables. They do not mark work as complete unless completion has been confirmed by the team. Update task status in the GitHub task board.

## Source basis

Prepared from the GR05 project proposal presentation (`GR05_Redesigned_Presentation(1).pptx`, 11 slides) and the team ownership agreed in the project setup discussion. Where a detail is not confirmed by the proposal or team, it is marked as requiring confirmation rather than assumed.
