# Project Scope, Objectives, Outcomes and Constraints

## 1. Scope stated in the proposal

The project proposal includes:

- Orders from January 2017 to August 2018.
- A MySQL staging area and a star-schema data warehouse.
- A Power BI Desktop dashboard.
- A predictive model to flag orders at risk of a 1–2-star review.
- Data from all nine Olist source files.

## 2. Objectives stated in the proposal

1. Build a MySQL star-schema warehouse from all nine source files.
2. Define and validate at least 12 relevant KPIs.
3. Create an interactive Power BI dashboard.
4. Build a model that flags orders at risk of a poor review (1–2 stars).

## 3. Expected project outcomes

- Documented data warehouse.
- Validated KPI catalogue.
- Interactive dashboard.
- Predictive model for poor-review risk.

These are overall project outcomes. They are not all expected to be completed by the 13 November milestone.

## 4. Constraints stated in the proposal

- Limited project time.
- Use of free tools only: MySQL Community and Power BI Desktop.
- Standard laptop hardware.
- Power BI Desktop runs on Windows only; the team must confirm how the required Power BI work will be carried out.
- The dataset is static, anonymised historical data (2016–2018).

## 5. Working tools and collaboration setup

The proposal identifies **MySQL 8.4 LTS**, **MySQL Workbench** and **Power BI Desktop** as the project technology choices.

The team has also established a collaboration and analysis workflow using GitHub, Visual Studio Code, Python and Jupyter Notebook. These are the team's working tools for version control, project coordination and Python-based analysis. They do not replace the database and BI tools selected in the proposal.

## 6. Current milestone scope — up to 13 November 2026

The work covered by this project-management version is limited to the preparation and presentation of the Week 46 milestone:

- Establish the business understanding, project roles, milestone plan, risk matrix and success criteria.
- Acquire and document the source data.
- Prepare an initial data dictionary / data-quality overview.
- Prepare an initial EDA report.
- Prepare schema diagrams (ERD) and SQL DDL for the proposed warehouse schema.
- Prepare and deliver the milestone presentation and demo.
- Record the feedback received.

## 7. Scope control

This version intentionally does not create a detailed work plan for activities after the 13 November 2026 milestone. The team will review the presentation feedback and then update the project documents for the next phase.
