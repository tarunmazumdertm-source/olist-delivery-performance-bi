# Olist Delivery Performance and Customer Satisfaction

## Project Overview
University BI & Big Data Analytics project using the Olist e-commerce dataset.

## Main Research Question
How is delivery performance related to customer satisfaction?

The project will use data analysis and Business Intelligence methods to explore this relationship.
