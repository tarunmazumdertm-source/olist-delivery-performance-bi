
# 02 — Data Acquisition

## 1. Overview

This folder contains documentation and information about
the Olist e-commerce dataset used in the BI & Big Data
Analytics project.

The project uses nine original CSV datasets.

## 2. Dataset Download Location

The original CSV files are stored in Google Drive
to avoid unnecessary storage in GitHub.

**Google Drive Dataset Folder:**

https://drive.google.com/drive/folders/18UaKUi23RyLpWwP0VCfA8H8RE5AjFkVw

Team members can use this link to view and download
the original datasets.

## 3. Source Information

- Dataset: Brazilian E-Commerce Public Dataset by Olist
- Source: Kaggle
- Geographic coverage: Brazil
- Data period: 2016–2018
- Project analysis period: January 2017 – August 2018
- Format: CSV

## 4. Source Files

The dataset contains nine CSV files:

1. olist_customers_dataset.csv
2. olist_geolocation_dataset.csv
3. olist_order_items_dataset.csv
4. olist_order_payments_dataset.csv
5. olist_order_reviews_dataset.csv
6. olist_orders_dataset.csv
7. olist_products_dataset.csv
8. olist_sellers_dataset.csv
9. product_category_name_translation.csv

## 5. Data Management

- Original source files remain unchanged.
- Raw CSV files are stored in Google Drive.
- GitHub stores project documentation and analysis code.
- Data quality checks are documented separately.
- Dataset access is provided through the shared Drive link.
