
# 03 — Data Dictionary and Data Quality

## 1. Overview

This folder contains the data dictionary, data profiling results,
data quality findings and Python profiling script prepared
for the Olist BI & Big Data Analytics project.

The purpose is to understand the structure, meaning,
relationships and quality of the nine source datasets.

## 2. Project Deliverables

| File | Description |
|---|---|
| Data Dictionary & Profiling.xlsx | Data dictionary and detailed profiling results |
| Data Dictionary_Profiling + KPIs.pptx | Summary of data understanding, quality findings and 12 KPIs |
| scripts/olist-profiling.py | Python script used for data profiling |

## 3. Data Dictionary

The dictionary documents 52 attributes across nine tables.

It includes:
- Column names and descriptions
- Primary and foreign key information
- Data types
- Example values
- Missing value percentages

## 4. Data Quality Profiling

The profiling covers:
- Data completeness
- Uniqueness
- Referential integrity
- Business rule consistency
- Missing values
- Duplicate records

The findings are documented in the Excel workbook and presentation.

## 5. KPI Catalogue

The profiling presentation includes 12 proposed KPIs covering:
- Sales
- Delivery performance
- Customer satisfaction
- Customer behaviour

The reported baselines must be validated during the analysis
before being used as final project results.
